# CLRS Fundamentals

A collection of implementations, experiments and notes developed while studying *Introduction to Algorithms* (CLRS).

The repository focuses on building a solid foundation in algorithms, data structures and algorithm analysis, with particular attention to concepts useful in backend engineering.

## Goals

The purpose of this repository is not simply to implement algorithms from the book.

The main objectives are to develop a deeper understanding of:

- asymptotic analysis;
- algorithm correctness;
- loop invariants;
- recurrence relations;
- data structures;
- algorithmic paradigms;
- computational trade-offs;
- time and space complexity.

## Languages

Two languages are used depending on the topic.

### C

C is used primarily for lower-level data structures and algorithms where explicit memory management and representation are useful for understanding the implementation.

Examples include:

- linked lists;
- hash tables;
- heaps;
- binary search trees;
- red-black trees;
- sorting algorithms.

### Java

Java is used primarily for higher-level algorithmic problems and abstractions.

Examples include:

- graphs;
- dynamic programming;
- greedy algorithms;
- graph traversal;
- shortest paths;
- other classical algorithms.

## Topics

The repository will gradually cover selected topics from CLRS, including:

- algorithm analysis;
- sorting;
- searching;
- data structures;
- hashing;
- trees;
- graphs;
- greedy algorithms;
- dynamic programming.

The goal is depth rather than exhaustive coverage of the book.
